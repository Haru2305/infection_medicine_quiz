# INFECT LAB — 感染症に使う薬を、作用機序から理解する

医学部CBT・QB感染症領域を解くための基礎を、**抗微生物薬の系統を主軸**に学ぶオリジナル講義＋4択クイズアプリ。主役は疾患の羅列ではなく「どの薬が、どの病原体の、どの仕組みを止めるか」です。

## メイン講義：29章（薬剤系統別）

**各薬剤の説明の中で前提知識から深掘り**します。例：アミノグリコシド系なら、DNA→mRNA→タンパク質、30S/50S、A/P/E部位、電子伝達系と膜電位、嫌気性菌に効かない理由、PK/PD、濃度依存性とPAE、腎毒性・耳毒性、耐性機構を一続きの講義で説明。

## 講義中に、分からない言葉が出てきたところで理解する

教材の冒頭に基礎用語集や必須のSTEP 0をまとめて置く方式は撤廃しました。**全71講義の本文と4択問題の問題文・解説中**で、専門用語の最初の出現場所にさりげない「?」を付けます。その語をクリック・タップすると直下に説明が開きます。別の画面への移動は不要です。

説明は「そもそも何か→正常時は何をしているか→何が障害されているか→臨床で何を見ればよいか」の流れ。さらに前提となる別の語へも、開いた説明の内側から追加で進めます（深掘りは最大2段階に制限し、循環参照や画面の肥大化を防止）。

- `inline-terms-base.js`：旧33概念の正常・異常の説明を文中から再利用
- `inline-terms-mechanisms.js`：薬理学・細菌壁・膜・免疫の詳しい用語
- `inline-terms-clinical.js`：臨床の解剖・検査・ウイルス・寄生虫の用語
- `inline-terms-pathogens.js`：カンジダ・結核菌・レジオネラ・HSV・HBV・HCVなど、病原体名が出た場所での説明
- `inline-terms-molecular-gaps.js`：DAA・cccDNA・HBs抗原・SOFA・VRE関連など、未定義だった分子機構・検査指標の説明
- `inline-terms.js`：本文を安全に解析し最初の該当語へ説明ボタンを挿入
- `lectures-ui.js` / `app.js`：講義本文・問題解説への埋め込みとタップ開閉

たとえば本文中の「PBP」に「?」が現れ、そこからペプチドグリカン→浸透圧へ、その場で理解を深められます。**今読んでいる内容が主、分からない言葉の説明が従**という構造です。概念の未収録・説明不足は引き続き監査して増補します。

## 解説本文の改稿方針 — ChatGPTの医学質問への回答と同じ密度にする

「専門用語の短い定義の羅列」ではなく、**読者がそこで持つ疑問に答え、正常時と異常時の比較から原因を説明し、最後にQBで正誤を判定できるまで掘る**文章を標準にする。薬・微生物・臨床・検査・選択肢・用語説明のすべてに同じ編集基準を適用する。

1. **まず何の話？**：未知の解剖・微生物・酵素・薬物動態を前提にしない
2. **正常時は？**：構造と機能、何を維持しているか
3. **なぜその異常になる？**：分子から臓器・症状・検査・合併症への因果関係
4. **他とどう違う？**：似ている疾患・薬剤・検査を区別し、QBの誤答が誤りの理由も書く
5. **その文章で初めて必要になった場所**で説明する：導入の総まとめや強制的な基礎章に戻さない

**2026-10-09現在の手作業による改稿範囲：** 38講義の354セクション（従来の23講義249セクションに、残りの抗ウイルス薬6講義・抗真菌薬4講義・抗原虫/駆虫薬5講義の合計105セクションを追加）。これで**メインの薬剤29講義は全セクションで詳細なQ&A形式の解説に改稿済み**および既存19問の解説と4択の理由。**まだ全71講義・全102問・全用語を改稿したわけではありません**。残る文章は従来の解説を保持しており、実例と読者からのフィードバックに基づいて同じ基準で編集する。

## 薬以外の感染症も「そもそも何？」から掘り下げる

薬剤29章に加え、病原体・感染症・免疫・検査を扱う**29講義すべて**に、原理・正常との比較・症状・検査の因果関係を教える詳細な3セクション（計87）を追加しました。前提は各講義本文に統合し、別の基礎講義を読まないと理解できない構成を避けています。

- Gram染色：クリスタルバイオレット→ヨウ素→脱色→対比染色の4工程から、Gram陽性/陰性で色が変わる理由へ。
- ウイルス・真菌・原虫：細胞構造・エンベロープ・生活環から感染部位や症状へ。
- 髄膜炎・肺炎・敗血症：正常な髄液・肺胞・循環から異常な検査値、合併症、治療へ。
- 免疫不全：好中球・抗体・補体・CD4 T細胞の役割から、なぜ特定の病原体が重症化するかへ。
- 既存4択102問の**解答直後**に、背景となる講義へ移れる「正解の暗記ではなく、仕組みから」のリンクを追加。正解・全誤答解説は既存どおり残しています。

ホームには薬剤講義への入口とは別に、**「感染症のしくみをゼロから」**を追加。補助資料は微生物学・免疫・検査・臨床などの分類別に整理しました。

`non-drug-depth-a.js` / `non-drug-depth-b.js` は87節の追加本文、
`non-drug-course.js` は既存29講義への差し込み、
`non-drug-gaps.js` はHPV・クリプトスポリジウム・便検査の補足、
`question-concept-links.js` は102問の学習リンクです。
