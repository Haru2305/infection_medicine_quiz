# INFECT LAB — 感染症クイズ

医学生向け、**感染症・感染微生物・抗微生物薬を初学からCBTレベルまで体系的に学ぶ**オリジナル4択クイズアプリ。

## 収録範囲

- 感染症の基礎（細菌／ウイルス／真菌／原虫／蠕虫の分類）
- 細菌学（Gram染色・菌種・感染症）
- 抗菌薬（作用機序・スペクトラム・薬剤耐性・PK/PD・副作用）
- ウイルス、抗ウイルス薬
- 真菌、抗真菌薬
- 原虫・寄生虫と治療
- 検査・感染経路別予防策・抗菌薬適正使用
- 臨床推論（ケース問題）

全問に **正解の解説／誤答3選択肢それぞれの理由／チェックポイント** を掲載。

## 詳しい講義（新設）

クイズとは独立して、**29講義・8分野の長文講義**を収録。アミノグリコシド系を含む薬剤機序だけでなく、病原体の構造、病態生理、検査、鑑別、治療・副作用まで段階的に扱います。

- ダッシュボードの「本格講義を読む」またはサイドバー／スマホ下部の「講義」タブから閲覧
- 各講義は見出し付きの連続セクションで構成。目次から章へジャンプ可能
- 8分野フィルタ、次の講義／前の講義、カテゴリ別クイズへの移動
- 読了状態は端末内保存。学習記録のJSONバックアップにも含める
- 既存102問の設問ID・学習履歴・解説は維持

講義データは `lectures.js`、閲覧画面は `lectures-ui.js`。新規講義は `{id,category,title,subtitle,sections:[{title,body}]}` 形式で追加できます。

**原稿について：** ユーザーが指定した過去のChatGPT共有リンク本文は取得できていないため、「過去チャットと完全同一の構成・密度」との照合は未実施です。今回の原稿は医学教育用に新規作成した初版です。薬剤の適応・推奨は個々の患者・施設・地域で異なります。

## 主な機能

- カテゴリ別演習・レベル別フィルタ・ランダム10問
- 1問ずつ解く、未学習だけ解く、直近不正解のみ復習
- ブックマーク、分野別進捗、累計正答率、直近の理解度
- 8枚のまとめノート
- 学習履歴はブラウザの `localStorage` に自動保存
- JSON形式で学習記録のバックアップ／復元
- PC・iPad・スマートフォン対応（1〜4キーで回答、Enterで次へ）

## 起動方法

**追加パッケージは一切不要。** `index.html` をブラウザで開くと使えます。インターネット接続はGoogle Fontsの取得時のみ必要で、未接続でもシステムフォントで動作します。

Webサーバーを使う場合：

```bash
python3 -m http.server 8000
# http://localhost:8000 にアクセス
```

GitHub Pagesで公開する場合は、GitHubリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を選択してください。リポジトリがprivateの場合、Pagesの利用条件はプランと組織設定を確認してください。

## 問題を追加する

`questions.js` に `add(id, category, level, question, options, answerIndex, explanation, reasons, point)` を追加します。

- `options`: 4選択肢
- `answerIndex`: 0〜3（A=0、D=3）
- `reasons`: 4選択肢分の根拠を必ず記載
- `category`: `basics` / `bacteria` / `antibiotics` / `viruses` / `fungi` / `parasites` / `diagnostics` / `clinical`
- `level`: 1（初学）/ 2（応用）/ 3（臨床）

問題IDは変更しないでください。IDは保存済みの学習記録と対応しています。

## 注意

これは**教育目的の概説**です。実際の感染症診療・抗微生物薬処方は、感染部位、重症度、培養・感受性、施設のアンチバイオグラム、ガイドライン、薬剤特性、アレルギー、腎肝機能、妊娠等の患者背景を総合して判断する必要があります。診療判断の代用には使用できません。

設問・解説は感染症/薬理学の標準的知識とCBT出題領域を参照して独自に書き起こしたもので、外部問題集の問題文を転載したものではありません。医学的内容は継続して更新してください。
