# INFECT LAB — 感染症に使う薬を、作用機序から理解する

医学部CBT・QB感染症領域を解くための基礎を、**抗微生物薬の系統を主軸**に学ぶオリジナル講義＋4択クイズアプリ。主役は疾患の羅列ではなく「どの薬が、どの病原体の、どの仕組みを止めるか」です。

## メイン講義：29章（薬剤系統別）

| 分野 | 章数 | 講義の主な内容 |
| --- | ---: | --- |
| 抗細菌薬 | 11 | 薬剤選択総論、ペニシリン、セフェム、カルバペネム、アミノグリコシド、テトラサイクリン、マクロライド、キノロン、抗MRSA薬、ST合剤・メトロニダゾール・リファンピシン、抗結核薬 |
| 抗ウイルス薬 | 7 | 複製サイクル、アシクロビル、CMV治療薬、インフルエンザ、HIV、HBV・HCV、COVID-19・RSV |
| 抗真菌薬 | 5 | 総論、アゾール、エキノキャンディン、アムホテリシンB・フルシトシン、表在性真菌症 |
| 抗原虫薬 | 3 | 抗マラリア薬、メトロニダゾールと原虫、トキソプラズマ治療薬 |
| 駆虫薬 | 3 | ベンズイミダゾール系、イベルメクチン、プラジカンテル |

**各薬剤の説明の中で前提知識から深掘り**します。例：アミノグリコシド系なら、DNA→mRNA→タンパク質、30S/50S、A/P/E部位、電子伝達系と膜電位、嫌気性菌に効かない理由、PK/PD、濃度依存性とPAE、腎毒性・耳毒性、耐性機構を一続きの講義で説明。

抗ウイルス薬ではウイルス複製過程、抗真菌薬ではエルゴステロールとグルカン、抗原虫薬・駆虫薬では生活環と寄生虫の細胞生理から薬効へつなぎます。「基礎の基礎」「微生物学」をメイン目次の独立章として強制的に読ませる構成にはしていません。

## 補助資料：42章（消去せず維持）

従来の感染症・病原体・細胞生物学・免疫・臓器生理・検査の講義は、講義一覧の **「補助資料」** タブから参照できます。従来の講義IDと既存の学習履歴を保持します。講義ごとの目次、検索、文字サイズ変更、読了記録を利用可能。

## 4択問題

元の **102問（細菌・抗菌薬・ウイルス・真菌・寄生虫・検査・臨床など）** は維持。正解だけでなく、誤答の各選択肢が間違っている理由まで解説します。29本の薬剤講義には既存の関連問題への直接リンクがあります。新しい教材はQBの問題文を転載したものではありません。

## アーキテクチャ

- `index.html` / `app.js`：静的アプリとクイズ、閲覧状態
- `lectures-ui.js` / `reading-theme.css`：スマホ・iPad対応の講義リーダー
- `lectures.js`：従来39講義の本文
- `foundation-roots.js` / `foundation-bridges-a.js` / `foundation-bridges-b.js` / `curriculum-init.js`：従来の基礎13講義と前提解説を保持
- `antibiotic-depth-a.js` / `antibiotic-depth-b.js`：抗細菌薬10講義の詳細解説追加
- `drug-antiviral.js` / `drug-antifungal.js` / `drug-antiparasitic.js`：抗ウイルス・抗真菌・抗寄生虫薬の講義本文
- `antibiotic-course.js`：主講義29章と補助資料42章の目次組立、確認問題との対応付け
- `questions.js`：4択102問と各選択肢の解説

依存パッケージ不要。GitHub Pagesでは **Settings → Pages → Deploy from a branch → main / (root)** で公開できます（リポジトリとプラン条件に注意）。

## 医学的注意

医学教育目的の解説です。病原体の薬剤感受性や耐性動向、患者の年齢・妊娠・免疫状態・臓器機能、感染部位、治療適応や各地域のガイドラインにより薬剤選択は変わります。個別の診療判断・処方の代用にはできません。
